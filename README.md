# Illuminations

A research series that looks at real-world questions through the lenses of
**complexity science, statistics, sociology, and behavioural economics** — and
tries to show its work. Each study is fully reproducible: open data in, open code,
figures and an interactive view out.

Companion to the writing at *Il Divano Color Senape*.

## Studies

|---|--------|-------|--------------|
| 01 | [economics](economics) | [Trophic structure of economies](economics/trophic-structure) | How deep do a country's production chains run — and does deepening them predict growth? |

## How this repo is organised

```
illuminations/
└── economics/
    └── trophic-structure/     ← study 01: data, code, figures, dashboard
```

Each study folder is self-contained, with its own README, a one-command data
download, a reproducible pipeline, and the figures it produces.

## Principles

- **Reproducible.** Every number traces back to a public source and a script in the repo.
- **Honest.** Caveats and failed hypotheses are reported alongside the headline result.
- **Open.** Sources are cited; derived data and figures are shareable under the terms below.
